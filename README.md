# L'ÉLIXIR | Luxury Perfume Showcase & WhatsApp Order Engine

An ultra-fast, mobile-first luxury fragrance showcase website designed for Sri Lankan perfume retailers dealing in **Inspired & Authentic** fragrances.

## ✨ Features
- **Luxury Aesthetic:** Obsidian Black and Champagne Gold theme inspired by high-end perfumeries.
- **Dynamic 50ml / 100ml Sizing:** Instant price and order link recalculation without page reload.
- **WhatsApp 1-Click Order Integration:** Pre-fills perfume name, selected size, and price directly into a WhatsApp order message.
- **Fragrance Pyramid (Pyramid Notes):** Top, Heart, and Base notes breakdown + Longevity ratings.
- **Sub-second Loading:** Pure HTML5, CSS3, and JavaScript with zero heavy dependencies.
